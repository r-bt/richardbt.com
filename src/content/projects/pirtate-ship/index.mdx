I designed and 3D printed this pirate ship for an assignment for How to Make Almost Anything (HTMAA) (6.9020) in 2022. The goal was to create something that suits additivie manufacturing methods.

In this case, I wanted to try using PVA dissolvable supports so included many elements such as sails, an internal hull, and railings along the side.
